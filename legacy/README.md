# Scripts históricos

Esta pasta preserva versões experimentais anteriores à estratégia principal com EMA 20.

Os arquivos deste diretório **não fazem parte do fluxo executado por `main.py`** e podem conter cálculos ou integrações que ainda precisam de revisão. Eles foram mantidos apenas como referência da evolução do projeto.

- `dmi.py`: experimento com ATR e DMI;
- `dpo.py`: experimento com ATR, DPO e DMI;
- `rsi.py`: experimento com RSI;
- `volume.py`: experimento de volume;
- `config_api.py`: modelo antigo de configuração da exchange.

Para executar o projeto atual, use o `main.py` localizado na raiz do repositório.
